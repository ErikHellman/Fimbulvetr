# M2 — Uppvík and the turning world — implementation plan

## Context

M1 is complete and verified (merged to `main` in PR #4): New Game → raid → Myrkviðr → Rótarhellir → `st_stone1_lit`. The user asked to execute **M2 "Uppvík + turning world"**. The spec row (§4) asks for:
- **Systems:** 5 weathers, snow and mud, spawn tables, trolls ↔ stone, economy, gear, galdr + seiðr, Eldr + fire spread, mead, a title screen with 3 slots, a settings UI.
- **Content:** the Uppvík hub, Myrkviðr +4, the völva, the huldra, the vargar hunt, +3 enemies.

The roadmap rhythm says a milestone brief must be approved before content is written. **Approving this plan approves the M2 brief below**, which Task 1 writes to `docs/briefs/m2.md`, as M1 did.

- GDD: `Fimbulvetr-game-design-document.md` (Uppvík, galdr, gear, seasons table, weather table)
- Spec: `docs/superpowers/specs/2026-09-26-fimbulvetr-design.md`

  - **M2a Turning world:** weathers, snow/mud/ice, spawn tables, trolls ↔ stone, rest-and-save, title with 3 slots, settings UI.

- **Compact Uppvík:** 4 screens, 5 interiors, 12 named NPCs.

### Enemies (+3), weather and spawns
- **`forest_troll`** (M2a core, M2c content):
  - Night only, reuses the troll behaviour, immortal and guarded.
  - At sunrise it turns into a liftable `troll_stone` that breaks into silver.
- **`vargr_alpha`** (M2c): the pack leader. A howl tell summons up to 2 vargr; a heavier lunge; 14 hp.
- **`rime_raven`** (M2c): the Rime King's raven at night. It circles; if it spots Ask, a 24-tick shriek tell calls a vargr, then it dives.
- **Weather** is rolled per region and day from the GDD table. Its effects:
  - rain: Eldr halved, outdoor braziers out, Uppvík NPCs go indoors
  - wind: bends projectiles and fire spread
  - fog: visibility radius 5 tiles, which the lantern extends
  - snow: in winter
- **Cover by season:**
  - winter snow (70%, the sword clears it), drifts (50%, only Eldr melts them)
  - spring mud next to water (75%, cannot be cleared, gone on clear days)
  - winter ice on freezing water (walkable)
- **Spawn tables** (region × season × night; night doubles the count), using authored spawn points:
  - Myrkviðr by day: vargr. By night: draugr, forest trolls and, from M2c, rime ravens.
  - Uppvík and Askdalr: none.

## Core interface changes (CLAUDE.md "plan first")

**`GameState`/`SaveData`: no change, and `SAVE_VERSION` stays 1.**
- Seiðr, `maxSeidr`, `purse`, `galdr[]`, weapon, armour and ring already exist.
- Burned and melted tiles are cover cleared bits.
- Weather, wind, spawns, snow, mud and ice are derived.
- Stone trolls are not saved.
- A fixture per part (`v1-m2a/b/c.json`) and every older fixture must load.

**The golden hash stays `f865b677`:** every new system returns early when idle, and new hashed keys are `undefined` unless in use.

- **`Sim`/`SimOptions`/`SimRt`**
  - `rolled?: boolean` (default true): rolled weather and spawn tables. The test Harness defaults it to **false**, so golden and `route_m1a/b/c` keep today's code path; the new tests set it.
  - New read-only `sky()` (the region's weather, even indoors, for conditions) and `wind(): Vec`.
  - `weather()` order: dev override → story rules → `weatherAt` → clear. It stays `clear` indoors and in dungeons.
  - `lights()` adds a fog radius and burning tiles.
  - `hash()` gains `fire` only while something burns.
  - `setLongDay(b)`, so the setting applies live.
- **`CoverGrid`:** new `wet` and `burn: Uint8Array`.
- **`buildCover`:** an optional `derive {terrain, outdoor, wet}`.
- **`CoverDef`:** gains `grows {on, by?}`, `cut?: false`, `burns?`, `melts?`, `walk?` (ice) and `cloak?`.
- **`COVERS`:** `snow`, `drift`, `mud`, `ice`.
- **`ContentDb`:** gains `galdr` and `spawns: Partial<Record<RegionId, SpawnTable>>`.
- **`ScreenDef`:** gains `spawns?: TilePos[]`.
- **`EnemyDef`:** gains `petrify?: PropId` and `weak?: Element[]` (double damage).
- **`DropTable`:** gains `seidr` (only new enemies use it, so old RNG draws are unchanged).
- **`PropDef`:** gains `loot?` and `burns?` (brambles).
- **`ItemDef`:** gains `seidr?`, `maxSeidr?`, `purse?` and `horn?`. `giveItem('purse')` now bumps `hero.purse`.
- **`Tuning`:** gains `armor`, `eldr`, `fire` and `weapons.uppvik_sword`.
- **Story**
  - `Cond {k:'weather', is}` (via a lazy `CondCtx.weather` thunk).
  - Effects `{k:'seidr', n}`, `{k:'learn', galdr}` and `{k:'armor', id}`.
  - Script step `{k:'save'}`, which blocks on `StoryRun.saving?`, plus `StoryUi {k:'save'}` and `Command {t:'saved'}`.
  - `StockEntry` becomes a union: `{item, n?} | {weapon} | {armor} | {galdr}`.
- **Actors**
  - `HeroMode` gains `cast`.
  - `stepProjectiles` dispatches on `def`: the boomerang (unchanged, plus wind on its outward leg) and `eldr`.
- **`ActorCtx`:** unchanged. Trolls spawn from night entries only, and `petrifyAtDawn` runs after the clock.
- **`DevQuery`/`DevPreset`:** gain `weather=<kind>|story` and `rolled`. The e2e `boot` helper pins `weather=story` unless a test asks otherwise.

## Risks
- **Golden hash and routes.** Covered by `rolled:false` in the Harness, idle early returns and optional hashed keys. The e2e `boot` pins `weather=story`. Only Uppvík NPCs move in rain. As a one-off, run the old routes with `rolled:true` and note the result in the ledger.
- **Title screen vs e2e.** Every dev query skips the title. Only `m2a.spec` walks through it.
- **Typed records.** Each new id lands with its record entries (`LOOKS`, `ENEMY_DEFS`, `SFX_BANK`, `COVER_ART`, `ITEM_DEFS`) in one commit.
- **Ice and sequence breaks.** Winter ice can reach islets such as `hp_myr_brook`. The GDD allows this ("every secret reachable by some tool"). The solver ignores cover, so its proofs stay conservative.
- **Seasonal lock-outs.** Fen-moss is autumn only, as the GDD intends. The quest is optional and gates nothing.
- **Dialogue volume.** 14 NPCs × 3+ states in en and sv. The Swedish goes to the user for proofreading, as always.
- **Budget.** 440.7 KB of 730 KB used; M2 is expected to add about 70–100 KB gzipped.
- **Scope.** 48 tasks. Each part ships alone. Stopping at a task boundary leaves a green build.
