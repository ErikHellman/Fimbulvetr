## How to run

```bash
pnpm install
pnpm dev          # http://localhost:5173 — dev query: ?screen=test_b&at=20,11&season=winter&time=22:00&nosave
pnpm check        # must be green before every commit
pnpm e2e          # Playwright, Chromium + WebKit (first: pnpm exec playwright install chromium webkit)
pnpm build && pnpm budget
```

- **Controls:**
  - WASD or arrows: move. J: sword; hold J to charge, then release to spin. Space: roll. Shift: shield.
  - A gamepad uses the standard mapping.
- **Dev keys** (dev and test builds only):
  - F1: overlay.
  - Backquote: console. Type `help`; the commands are warp, time, season, flag, lang, volume, save, export and import.

## Decisions made during M0 (rulings)
Each line reads: what was decided — why — what it costs if wrong. The full context is in the ledger.

1. **Execution on branch `m0-foundations` in the main checkout, not a separate worktree.** Why: the branch is isolated from `main`. Cost if wrong: none.
2. **Co-Authored-By trailers name the model that actually wrote each commit** (Haiku 4.5 / Sonnet 5 / Opus 5.5), not the plan's uniform "Claude Opus 5.5". Why: truthful attribution. Cost if wrong: cosmetic; the commits can be reworded before merge.
3. **The WebGL-required message was English-only for a few commits** until the i18n task replaced it. Cost if wrong: none now; it is fixed.
4. **`eslint.config.js` added to the tsconfig include** so its `@ts-check` is enforced. Why: an inert pragma is not a gate. Cost if wrong: none.
5. **`loadSave` rejects a save with a missing `state` as `invalid` instead of crashing.** This departs from the plan's reference code. Why: the spec's never-crash-on-import rule. Cost if wrong: none.
6. **`Sim.spawn` uses `.map` rather than `switch`** on the one-variant `Thing` union, because lint rejects an always-true check. Carried to M1 as above. Cost if wrong: an M1 variant could be mis-spawned as an enemy until tests catch it.
7. **The hero's walk bob goes down 1 px instead of up.** Why: going up clipped the mandated 2 px outline on 16 frames; a test now guards the margins. Cost if wrong: cosmetic.
8. **The canvas `aria-label` was restored** after the plan's `main.ts` rewrite dropped it. Cost if wrong: none.
9. **The JS budget counts every `.js` file under `dist/`, including the service worker and the Workbox runtime**, and gives a clear error when `dist/` is missing. Cost if wrong: none.
10. **Input fix: key taps shorter than a frame are no longer lost.** `KeyboardState.takeCodes()` returns held plus tapped keys each sample, and the exit test uses real taps again. Cost if wrong: none.
11. **Final fix wave: one pass covering 12 findings.** Besides #10, it:

    - stopped a NaN gamepad axis from freezing the loop, and guarded `getGamepads`;
    - made import autosave a snapshot of the imported state;

    - deduplicated clock logic in the dev query;
    - set `<html lang>` from the chosen language;
    - deepened the tests (determinism across a screen transition, save content, animation names);
    - fixed the warp argument validation.

    Cost if wrong: a slightly larger final diff.
12. **Remaining minors are carried to the milestones whose features exercise them** (the list above). Cost if wrong: small rework later.
