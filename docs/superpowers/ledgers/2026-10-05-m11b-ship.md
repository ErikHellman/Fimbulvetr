## Safari audit

| Area | Finding | Action |
| --- | --- | --- |
| Audio unlock | Phaser unlocks Web Audio on the first gesture and resumes a `suspended` or `interrupted` context on focus (iOS). | None. |
| `localStorage` | Every access goes through `browserStorage()` or try/catch (settings, achievements, tab lock). | None. |
| IndexedDB | `openSaveStoreSafely` starts the game without saves when it is missing or refused; a blocked open is reported. | None. |
| Eviction | `navigator.storage.persist()` is asked once, inside try/catch; export stays the safety net. | None. |
| Newer APIs | No `requestIdleCallback`, `structuredClone`, `OffscreenCanvas`, `createImageBitmap`, Fullscreen API or File System Access in the shell. The bundle uses `Object.hasOwn` (Safari 15.4) and targets ES2022. | README names Safari 15.4 or newer. |
| Canvas and textures | The tileset is 576 × 1278 px, sprite pages are 2048 px wide, and the font pages are small at every size: all within 4096, the limit of older iPhones and iPads. | Guard test `textureLimits`. |
| Downloads | Export uses a Blob URL and an `a[download]`, revoked after a second, which Safari accepts. | None. |
| Rendering | `image-rendering: pixelated` on the canvas; integer scaling by default. | None. |

WebKit is not installed in this container, so the user's playtest covers Safari itself.
